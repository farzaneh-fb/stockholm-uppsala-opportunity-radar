# Stockholm–Uppsala Opportunity Radar

A static GitHub Pages dashboard for tracking tailored PhD and job opportunities in Stockholm and Uppsala.

The report includes:

- separate PhD and job tabs;
- transparent profile-fit scores and gaps;
- position-specific RenderCV YAML/PDF downloads;
- browser-local application tracking;
- responsive light and dark modes;
- source and application links.

The master CV and local render/test artifacts are intentionally excluded from this public repository.
